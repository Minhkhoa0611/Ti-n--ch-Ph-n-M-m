Một số câu lệnh tối ưu máy tính (chạy trong CMD/PowerShell)
Hướng dẫn: Bôi đen lệnh cần dùng, nhấn Ctrl+C để copy, sau đó dán vào cửa sổ CMD hoặc PowerShell (chạy với quyền Admin nếu cần).

🧹 Dọn dẹp & Tối ưu hệ thống
1. Dọn rác hệ thống (Disk Cleanup): 
cleanmgr
2. Xóa file tạm thời: 
del /s /q %temp%\*
3. Xóa file tạm trong thư mục Windows: 
del /s /q C:\Windows\Temp\*
4. Mở thư mục Startup (quản lý ứng dụng khởi động): 
shell:startup
5. Tắt các ứng dụng khởi động cùng Windows (msconfig): 
msconfig

🛠️ Sửa lỗi & Kiểm tra hệ thống
6. Kiểm tra và sửa lỗi ổ đĩa: 
chkdsk /f /r
7. Sửa file hệ thống Windows: 
sfc /scannow
8. Quét và sửa lỗi Windows Update: 
DISM /Online /Cleanup-Image /RestoreHealth
9. Kiểm tra trạng thái ổ cứng (SMART): 
wmic diskdrive get status

📋 Thông tin hệ thống & driver
10. Xem thông tin hệ thống: 
systeminfo
11. Xem danh sách driver đã cài: 
driverquery

⚙️ Quản lý tiến trình
12. Xem các tiến trình đang chạy: 
tasklist
13. Tắt tiến trình (ví dụ: notepad.exe): 
taskkill /IM notepad.exe /F

🌐 Mạng & Internet
14. Xem địa chỉ IP máy tính: 
ipconfig
15. Xem chi tiết mạng (IP, Gateway, DNS...): 
ipconfig /all
16. Xóa cache DNS: 
ipconfig /flushdns
17. Kiểm tra kết nối mạng tới google.com: 
ping google.com
18. Kiểm tra tốc độ mạng tới 8.8.8.8: 
ping 8.8.8.8 -t
19. Xem các cổng mạng đang mở: 
netstat -an
20. Đặt lại card mạng (reset network): 
netsh int ip reset
21. Đặt lại Winsock: 
netsh winsock reset
22. Tắt bật card mạng (ví dụ: Ethernet): 
netsh interface set interface "Ethernet" admin=disable
netsh interface set interface "Ethernet" admin=enable
23. Kiểm tra tốc độ mạng (PowerShell): 
Test-NetConnection google.com

💾 Quản lý ổ đĩa
24. Mở Disk Management: 25. Xem dung lượng ổ đĩa: 
wmic logicaldisk get size,freespace,caption
26. Chống phân mảnh ổ đĩa: 
defrag C: /O

👤 Quản lý tài khoản người dùng
27. Xem danh sách user: 
net user
28. Đổi mật khẩu user (ví dụ: admin): 
net user admin *
29. Tạo user mới (ví dụ: newuser): 
net user newuser /add
30. Thêm user vào nhóm Administrators: 
net localgroup administrators newuser /add

📋 Clipboard & tiện ích nhỏ
31. Xem lịch sử clipboard (Windows 10+): 
Windows + V
32. Chụp màn hình nhanh: 
Windows + Shift + S
33. Mở Task Manager: 
Ctrl + Shift + Esc

🔄 Windows Update & bảo mật
34. Kiểm tra cập nhật Windows: 
ms-settings:windowsupdate
35. Tắt Windows Defender tạm thời (PowerShell Admin): 
Set-MpPreference -DisableRealtimeMonitoring $true
36. Bật lại Windows Defender: 
Set-MpPreference -DisableRealtimeMonitoring $false

🪟 Một số lệnh mở nhanh ứng dụng hệ thống
37. Mở Control Panel: 
control
38. Mở Device Manager: 
devmgmt.msc
39. Mở Services: 
services.msc
40. Mở Registry Editor: 
regedit
41. Mở Group Policy Editor (Windows Pro): 
gpedit.msc

🖨️ Quản lý in ấn
42. Mở hàng đợi máy in: 
control printers
43. Xóa tất cả lệnh in bị kẹt: 
net stop spooler && del /Q /F %systemroot%\System32\spool\PRINTERS\* && net start spooler

🧑‍💻 Một số lệnh PowerShell hữu ích
44. Xem danh sách phần mềm đã cài: 
Get-WmiObject -Class Win32_Product | Select-Object Name, Version
45. Xem thông tin pin laptop: 
powercfg /batteryreport /output %USERPROFILE%\Desktop\battery-report.html
46. Xem thông tin mạng WiFi đã lưu: 
netsh wlan show profiles
47. Xem mật khẩu WiFi đã lưu (thay tên_wifi): 
netsh wlan show profile name="tên_wifi" key=clear

🧰 Khác
48. Mở cửa sổ Run: 
Windows + R
49. Mở This PC (File Explorer): 
Windows + E
50. Khóa nhanh máy tính: 
Windows + L

🌐 Chạy server nội bộ (Local server)
Lưu ý: Các lệnh này giúp tạo server nội bộ để phát triển web, kiểm thử ứng dụng, chia sẻ file...

1. Python 3 - Chạy HTTP server tại thư mục hiện tại (port 8000): 
python -m http.server 8000
2. Python 2 - Chạy SimpleHTTPServer (port 8000): 
python -m SimpleHTTPServer 8000
3. PHP - Chạy server tại thư mục hiện tại (port 8000): 
php -S localhost:8000
4. Node.js - Chạy server với http-server (cần cài đặt http-server): 
npx http-server -p 8000
5. Powershell - Chia sẻ thư mục qua HTTP (port 8080): 
powershell -Command "Start-Process powershell -ArgumentList '-NoExit','-Command','cd %cd%; python -m http.server 8080'"
🛸 Kích hoạt tính năng ẩn của Windows
Lưu ý: Một số lệnh cần quyền Admin, có thể cần khởi động lại máy để áp dụng.

1. Hiện file/thư mục ẩn trong Explorer: 
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced" /v Hidden /t REG_DWORD /d 1 /f
2. Hiện file hệ thống bảo vệ: 
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced" /v ShowSuperHidden /t REG_DWORD /d 1 /f
3. Bật GodMode (tạo thư mục GodMode): 
mkdir "%USERPROFILE%\Desktop\GodMode.{ED7BA470-8E54-465E-825C-99712043E01C}"
4. Bật Clipboard History (Windows 10+): 
ms-settings:clipboard
5. Bật Dark Mode cho Windows: 
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize" /v AppsUseLightTheme /t REG_DWORD /d 0 /f
6. Bật tính năng Sandbox (Windows Pro): 
dism /Online /Enable-Feature /FeatureName:"Containers-DisposableClientVM" /All
7. Bật Hyper-V (ảo hóa, Windows Pro): 
dism /Online /Enable-Feature /All /FeatureName:Microsoft-Hyper-V
8. Bật tính năng Telnet Client: 
dism /online /Enable-Feature /FeatureName:TelnetClient
9. Bật tính năng .NET Framework 3.5: 
dism /online /enable-feature /featurename:NetFx3 /all
⚠️ Lệnh NGUY HIỂM - Cẩn thận khi sử dụng!
CẢNH BÁO: Các lệnh dưới đây có thể gây mất dữ liệu, lỗi hệ thống hoặc không thể phục hồi. Chỉ sử dụng khi bạn hiểu rõ hậu quả!

❌ Format ổ đĩa (XÓA TOÀN BỘ DỮ LIỆU Ổ ĐĨA!)
1. Format ổ D: 
format D: /fs:ntfs /q
❌ Xóa user khỏi máy tính
2. Xóa user (ví dụ: nguyenvanA): 
net user nguyenvanA /delete
❌ Xóa file hệ thống (cực kỳ nguy hiểm!)
3. Xóa toàn bộ file trong System32: 
del /f /s /q C:\Windows\System32\*
❌ Tắt máy/tự động khởi động lại
4. Tắt máy ngay lập tức: 
shutdown /s /f /t 0
5. Khởi động lại ngay lập tức: 
shutdown /r /f /t 0
❌ Xóa phân vùng ổ đĩa (mất hết dữ liệu!)
6. Xóa phân vùng qua diskpart: 
diskpart
list disk
select disk 1
clean
exit
❌ Gỡ cài đặt phần mềm hàng loạt (PowerShell)
7. Gỡ tất cả app cài từ Store (Windows 10+): 
Get-AppxPackage | Remove-AppxPackage
